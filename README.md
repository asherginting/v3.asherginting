# AAG — Personal Portfolio

> Open to remote opportunities — available for global collaboration.

A modern, performance-focused personal portfolio built with the latest **Next.js 16** and **React 19**, showcasing my work, experience, and technical skills as a software engineer.

Designed with a strong emphasis on **clarity, scalability, and clean user experience**.

---

## 🌐 Live

* **Website**: https://asherginting.me
* **Repository**: https://github.com/asherginting/v3.asherginting

---

## ✨ Highlights

* ⚡ Built with **Next.js 16 (App Router + Turbopack)**
* ⚛️ Powered by **React 19**
* 🎨 Minimalist UI with custom typography (Apercu)
* 🌗 Light / Dark mode with system preference support
* 🎞️ Smooth animations using Framer Motion
* 📱 Fully responsive across devices
* 🧩 Scalable and modular architecture
* 🚀 Optimized for performance and accessibility

## 🚀 Getting Started

Install dependencies:


```bash

```

Build for production:

```bash
pnpm build
pnpm start
```
